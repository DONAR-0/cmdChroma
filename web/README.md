# cmdChroma Web Module

Standalone web interface for cmdChroma.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

The app will be available at http://localhost:3000.

## Build

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Type Checking

```bash
npm run typecheck
```

## Linting

```bash
npm run lint
```

## Environment Variables

Create a `.env` file with:

```env
VITE_API_URL=http://localhost:6700
VITE_API_KEY=your-api-key
```
